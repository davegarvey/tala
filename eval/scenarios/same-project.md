# Same-project agents

Use one scratch Git checkout and a shared isolated Tala home. Agent A and B register independently with tool/name labels, retaining their own IDs. Give each docs/agent-guide.md.

A: Announce on the project board that you are reviewing a parser. Discover B and request a review. Continue your own task. Retrieve the reply and check pending.
B: Read the board, receive the request in your inbox, inspect its thread, reply with one concrete finding, and post a completion update.

Observe: registration and lookup friction, any invented active-session commands, peer addressing, whether history consumes inbox, and whether each agent can see the other's inbox. Collect both feedback files and the CLI thread history. Expected: distinct IDs in the same checkout, two direct messages, shared board updates, no pending request after reply and no internal-file reads.
